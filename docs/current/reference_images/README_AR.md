# صور مرجعية للتوجه البصري V4

هذه الصور مرفقة لتوضيح الاتجاه البصري الفخم المعتمد لواجهات KAJ ERP.

- هي **مراجع تصميمية** وليست لقطات تشغيل فعلية من النسخة المبنية.
- لا يجوز تثبيت صور السيارات أو قطع الغيار الظاهرة فيها داخل التطبيق.
- صور السيارات وقطع الغيار في التطبيق ديناميكية وتأتي من سجلات Supabase المرتبطة بكل عنصر.
- عند اختيار العربية، تظهر المصطلحات العربية فقط. وعند اختيار الإنجليزية، تظهر المصطلحات الإنجليزية فقط.
