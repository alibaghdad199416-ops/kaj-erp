# Quality Line ERP 21.4.0 — المرحلة الخامسة

إعادة بناء التجربة التجارية للمبيعات والمشتريات ومسارات الأوامر والفواتير والدفعات والطباعة ضمن هوية KAJ Signature.

## النطاق
- مركز المبيعات وأوامر البيع.
- مركز المشتريات وأوامر الشراء.
- بطاقات الفواتير والمدفوعات والحالات.
- تبويبات العمليات ومسارات الموافقة.
- تحسين الترجمة الفعلية للعربية والإنجليزية.
- المحافظة على منطق Supabase والمحاسبة والطباعة.
