# Quality Line ERP 21.5.0 — KAJ Signature Phase 6

تم توحيد المركز المالي والمحاسبي ومركز الإعدادات والإدارة ضمن نظام KAJ Signature، مع دعم ثنائي اللغة للأقسام الرئيسية، وتثبيت مكونات تنفيذية مشتركة للمؤشرات والأسطح والحالات.

لا تتضمن المرحلة تغييرات على مخطط قاعدة البيانات أو migrations جديدة.
