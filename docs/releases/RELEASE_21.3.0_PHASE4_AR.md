# الإصدار 21.3.0 — المرحلة الرابعة

تم توحيد واجهات الصيانة والشركاء التجاريين وخدمة العملاء والفرص التجارية ضمن KAJ Signature.

## النطاق
- مركز صيانة تنفيذي ومسار مراحل موحد.
- نموذج صيانة منظم للمركبة والخدمات والمواد والتسعير والمراجعة.
- مركز شركاء ثنائي اللغة للعملاء والموردين.
- بطاقات فرص تجارية موحدة مع حالة وربط مباشر بأمر البيع.
- إزالة AppBar الداخلي المكرر من نموذج الفرصة داخل نافذة مساحة العمل.
- توحيد عناوين نوافذ الإضافة والتعديل حسب اللغة النشطة.
