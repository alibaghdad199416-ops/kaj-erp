# Quality Line ERP 22.7.0 — المرحلة 8

إعادة بناء طبقة الإدارة المؤسسية الخاصة بالإعدادات والمستخدمين والأدوار والصلاحيات والمراقبة والسجلات والفترات التشغيلية والنسخ الاحتياطية وسلة المحذوفات.

## المكونات المشتركة

- `KajAdminWorkspace`
- `KajAdminMetricData`
- `KajAdminSection`
- `KajAdminState`

## النطاق

- مركز الإعدادات والتحكم.
- إعدادات الشركة والفروع والعملات والنسخ الاحتياطية.
- المستخدمون والوظائف والأدوار والصلاحيات المخصصة.
- سجل التدقيق ومحاولات الوصول.
- مراقبة الاتصال والمزامنة وجاهزية الإنتاج.
- الفترات التشغيلية المفتوحة والمغلقة.
- سلة المحذوفات والاستعادة والحذف النهائي والتصدير.

هذه نسخة معاينة، ويجب تشغيل Flutter Analyze والاختبارات والبناء واختبار الواجهات بصرياً قبل النشر.
